# style

The Sustainable FSA house-style kit: design tokens, theme CSS, and ES-module
helpers for the project's single-page web mapping applications, served
same-origin to every project site at `https://sustainable-fsa.com/style/`.

Scaffold commit — full kit lands with v0.1.0. Architecture modeled on
[mt-climate-office/mco-web-style](https://github.com/mt-climate-office/mco-web-style) (MIT).
